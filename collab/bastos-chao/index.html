Questions only this platform can answer

Twelve candidates came from four independent brainstorms: mechanism of prediction, subjective report, action and body, and cross-scale bridges. Three adversarial reviewers then checked each one. Novelty is a literature search for whether the question is already answered. Necessity asks whether the Bastos lab alone, the Chao lab alone, or epilepsy microwire recordings could answer it. Feasibility asks whether it works in tetraplegic Utah-array participants with S1 stimulation and limited session time. Scores are out of 10. The literature checks are one reviewer's web searches and have not been confirmed independently.

How this was built

Coding. Each CV was read and coded by hand onto 45 concepts (listed in the inspector for every person). A concept was coded when the CV shows a paper, preprint, poster, project or listed skill in it. Stated interests count only when there is no other evidence for that person (for example, Sali Rahman's interest in predictive processing).

Distance. Jaccard similarity = shared concepts ÷ concepts held by either person; distance = 1 − similarity. Every concept counts equally, so a PI with a long CV overlaps more with everyone.

Caveats. CVs differ in length and detail; trainee CVs list fewer areas. Heng Zhang's current position is Kyushu University; he is included because his CV was in the Chao-lab set and he co-authors with Zenas Chao.
